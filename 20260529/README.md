# HL2class - Live Greeting & Time Widget

A premium, highly aesthetic landing page widget featuring a live clock and personalized introduction for **Hiro Lee**.

🔗 **Live Demo**: [https://hirohirolee.github.io/HL2class/#](https://hirohirolee.github.io/HL2class/#)


## 🚀 Features

- **Glassmorphic UI Design**: Uses modern CSS `backdrop-filter` with rich translucency, subtle glowing borders, and drop-shadows.
- **Ambient Animated Background**: Soft color-shifting spheres float dynamically in the background for a modern, fluid aesthetic.
- **Interactive 3D Parallax Card**: The profile card tilts responsively to follow mouse movements, creating a smooth tactile feedback experience.
- **Real-Time Live Clock**: A dynamic JavaScript-driven clock showing:
  - Hours, minutes, and seconds (12-hour format with AM/PM).
  - Ticking visual indicator.
  - Full calendar date formatting.
  - Detected system timezone display.
- **Fluid Responsiveness**: Adapts seamlessly to all device screen sizes from desktop monitors to mobile phones.

## 🛠️ Built With

- **HTML5**: Semantic markup structure.
- **Vanilla CSS3**: Layout, glassmorphism design tokens, floating background light animations, and keyframes.
- **Vanilla JavaScript (ES6)**: Dom manipulation, time formatting clock engine, and vector tracking card-tilt animations.
- **Typography**: Imported Google Fonts (`Outfit` and `Space Mono`).

## 💻 How to Run Locally

Since this project consists of raw HTML, CSS, and JS, you can run it directly:

1. Double-click the `index.html` file to open it in any modern web browser.
2. Alternatively, serve it locally using a simple Python server:
   ```bash
   python -m http.server 8000
   ```
   Then open `http://localhost:8000` in your web browser.
