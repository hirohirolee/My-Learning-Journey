## 第一段：核心資料表切換（supabase_db.py）

### 變更檔案：[supabase_db.py](file:///d:/Projects/My-Learning-Journey/group-project/supabase_db.py)

### 修改一：環境變數預設值更新
* 將模組頂層的 `SUPABASE_TABLE_NAME` 預設值從 `"reviews_enriched"` 改為 `"master_reviews_enriched"`。
* 確保即使 `.env` 未設定，系統也會指向正確的新資料表。

### 修改二：動態 Client 預設值同步
* `init_dynamic_client()` 函數的 `table_name` 預設參數同步更新為 `"master_reviews_enriched"`。

### 修改三：欄位白名單重構（空表防護）
* 將空表防護白名單重構為對齊 `master_reviews_enriched` 的實際欄位：
  ```
  review_id, reviewer, review_time, raw_text, rating,
  platform, sentiment, sentiment_label, risk_percent, report_content, engine
  ```
* 移除不存在的 `embedding` 欄位，避免 Supabase schema cache 報錯。

### 修改四：欄位寫入欄位名稱對齊
* `save_pr_report()` 中將 `"review"` 鍵改為 `"raw_text"`，完整對齊資料庫欄位名稱。

### 修改五：None 值安全過濾（新增）
* 在最終 insert 前加入 `{k: v for k, v in data.items() if v is not None}`。
* 防止 Supabase 因收到 `null` 值的不存在欄位而拒絕整筆寫入。

### 修改六：`fetch_all_reports()` 排序邏輯補強
* 新增以 `review_id` 排序的分支（原本只有 `created_at` 和 `id`），配合新資料表主鍵。
