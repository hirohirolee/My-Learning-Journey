## 第二段：危機評估與公關報告輸出 JSON 規格化

### 設計要求
* **法務與公關專家定位**：針對第一關攔截判定為實質商譽危機的事件進行深度分析。
* **標準 JSON 輸出**：
  * 精準產出含有三個欄位：`risk_percent`（0.70 到 1.00 浮點數）、`sentiment`（`High Risk` 或 `Medium Risk`）、`report_content`。
