## 📂 專案架構說明
為了提升維護性與專業度，本專案採用模組化管理：
- `portfolio/`: 存放各階段的網頁作品集。

- `daily_lessons/`: 存放每日學習紀錄與筆記。

## 📝 重要開發日誌與除錯紀錄
本專案紀錄了我如何解決開發過程中的關鍵挑戰：
1. **路徑管理**: 成功解決檔案遷移後的資源讀取錯誤 (404)，透過相對路徑 `../` 精確指向根目錄資源。
2. **部署流程**: 建立開發工作流，透過「清空快取」解決 GitHub Pages 更新延遲問題。
3. **功能實現**: 運用 `DOMContentLoaded` 與定時器實作即時時鐘功能，並採用 Flexbox 進行響應式設計。
4. **效率提升**: 設定 Git 別名 (`git pushall`) 以簡化開發同步流程。
