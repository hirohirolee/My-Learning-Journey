# 中央氣象署 (CWA) 天氣預報資料下載器

本專案提供一個簡單的 Python 腳本，用來從「中央氣象署氣象資料開放平臺」下載最新的天氣預報 JSON 資料，並直接儲存至您的電腦桌面。

## ⚠️ 重要說明 (關於一週農業氣象預報)
您原先想下載的 **「一週農業氣象預報 (F-A0010-001)」**，經確認已於中央氣象署開放資料平臺**下架並停止更新**。

為了滿足您的需求，本腳本提供了以下替代資料集選項：
1. **台灣各縣市一週天氣預報 (`F-C0032-005`)** *(最推薦替代)*
2. **全臺灣各鄉鎮市區預報資料（未來一週）(`F-D0047-091`)** *(更細緻的地區預報)*
3. **農業氣象觀測網旬資料 (`C-A0008-001`)** *(歷史與十日觀測統計)*

---

## 🚀 使用步驟

### 1. 取得 API 授權碼 (Authorization Key)
氣象署 API 需要授權碼才能存取。如果您還沒有，請按照以下步驟免費申請：
1. 前往 [中央氣象署氣象資料開放平臺](https://opendata.cwa.gov.tw/)。
2. 註冊並登入會員。
3. 進入「會員專區」->「個人資料」即可複製您的 **「API 授權碼」**。

### 2. 執行下載腳本

本腳本僅使用 Python 內建標準庫 (`urllib` 與 `json`)，**不需要額外安裝任何第三方套件** (如 `requests` 等)，可直接執行：

開啟終端機 (PowerShell 或 Command Prompt)，切換到本專案目錄並執行：
```bash
python download_cwa_forecast.py
```

### 3. 執行過程
- 執行後，腳本會提示您輸入 **API 授權碼**。
- 接著您可以選擇要下載哪一個資料集 (輸入 `1`、`2`、`3` 或自訂 ID)。
- 下載成功後，JSON 檔案將會自動以漂亮排版 (Formatted JSON) 儲存至您的 **桌面 (Desktop)**。
