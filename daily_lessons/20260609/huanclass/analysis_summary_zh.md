# 50 Startups 利潤預測與迴歸分析成果彙整報告

本報告彙整了針對 `50_Startups.csv` 數據集，遵循 **CRISP-DM** 流程所進行的機器學習建模與分析成果。報告特別針對極端值清洗、0值保留、特徵縮放以及多元共線性預防進行了優化處理。

---

## 1. 商業與資料理解 (Business & Data Understanding)
* **核心目標**：利用企業在**研發支出 (R&D Spend)**、**行政管理 (Administration)**、**行銷推廣 (Marketing Spend)** 的投入以及所在的**地區 (State)**，來精準預測其產出的**利潤 (Profit)**。
* **資料集特徵**：共 50 筆記錄，包含 3 項數值型支出特徵、1 項地區類別特徵，以及目標變數 Profit。

---

## 2. 數據清洗與準備 (Data Preparation)

為了確保迴歸模型的準確性與假設前提，我們在資料準備階段執行了以下關鍵處理：

### 1) 極端值剔除 (IQR Outlier Filtering)
利用四分位距 (IQR) 檢驗目標欄位 `Profit` 的分布：
* **IQR 範圍**：\$49,627.07
* **極端低值門檻 (Lower Bound)**：\$15,698.29
* **偵測結果**：**Index 49** 的 Profit 為 **\$14,681.40**，低於門檻，被判定為極端值。
* **處理方式**：在資料準備階段直接**剔除 (Drop)** 該筆資料（Index 49），使建模樣本數調整為 49 筆，以防干擾迴歸線擬合。

### 2) 數值為 0 的欄位處理
* 數據集中有部分欄位值為 0（例如 Index 47 的 R&D Spend，以及 Index 19, 47, 48 的 Marketing Spend）。
* **處理方式**：這些 0 值代表特定的商業模式（如無行銷預算或草創階段），屬於真實業務特徵而非缺失值，因此**保持原樣，不進行平均值填補**。

### 3) 類別變數編碼 (Avoid Dummy Variable Trap)
* 針對地理位置欄位 `State`（包含 California, Florida, New York）進行 One-Hot Encoding。
* **處理方式**：設定 `drop_first=True`，剔除 baseline 地區（California），僅保留 `State_Florida` 與 `State_New York`。此舉能有效避開**虛擬變數陷阱 (Dummy Variable Trap)**，預防多元共線性。

### 4) 特徵標準化縮放 (Selective Feature Scaling)
* **處理方式**：僅針對 `R&D Spend`, `Administration`, `Marketing Spend` 這三個連續型數值特徵使用 `StandardScaler` 進行標準化縮放（均值為 0，標準差為 1）。One-Hot 編碼後的二元虛擬變數（0 或 1）保持原樣不縮放，以維持可解釋性。

---

## 3. 模型建立與效能對比 (Modeling & Evaluation)

我們將清洗後的資料按 80% 訓練集與 20% 測試集進行切分（固定隨機種子 `random_state=42`），並建立了**多元線性迴歸 (OLS)** 與**隨機森林迴歸 (Random Forest)** 兩個模型。

### 測試集定量對比
| 評估模型 | R-squared ($R^2$ 決定係數) | 平均絕對誤差 (MAE) |
| :--- | :---: | :---: |
| **多元線性迴歸 (Linear Regression)** | **0.91908** | **\$6,550.86** |
| **隨機森林迴歸 (Random Forest)** | **0.92601** | **\$6,892.37** |

* **對比結論**：
  * 隨機森林迴歸模型在 $R^2$ 上表現稍好（0.92601），解釋了測試集中 92.6% 的利潤變異。
  * 多元線性迴歸模型則在 MAE 表現上更優，平均預測誤差僅為 **\$6,550.86**。

## 4. 特徵權重與重要性分析 (Feature Weights & Importance)

### 1) 多元線性迴歸特徵權重 (標準化係數)
反映當特徵增加 1 個標準差時，利潤的變化幅度：
1. **R&D Spend**：**+34,885.07**（絕對主導力量，正面影響最大）
2. **Marketing Spend**：**+4,342.70**（次要正面影響）
3. **State_New York**：**-2,877.86**（相較於加州，紐約州有些微負面係數）
4. **State_Florida**：**-1,860.88**（相較於加州，佛州有些微負面係數）
5. **Administration**：**-425.04**（行政管理支出呈現極微弱的負面影響）

#### 複線性迴歸數學方程式 (原始未縮放數據)：
```text
Profit = 54,028.04 + 0.8056 * (R&D Spend) - 0.0688 * (Administration) + 0.0299 * (Marketing Spend) + 938.7930 * (State_Florida) + 6.9878 * (State_New York)
```
* **解讀**：在控制其他條件不變的情況下，研發費用每增加 \$1.00，利潤預期增加 **\$0.81**；行銷費用每增加 \$1.00，利潤預期僅增加 **\$0.03**；行政費用每增加 \$1.00，反而會減少 **\$0.07** 的利潤。地區別的影響極小且在統計上不顯著。

### 2) 隨機森林特徵重要性 (Feature Importance)
基於樹狀分裂貢獻度的權重分配：
* **R&D Spend (研發支出)**：**91.69%** (決定性特徵)
* **Marketing Spend (行銷支出)**：**7.29%**
* **Administration (行政管理)**：**0.77%**
* **State_New York (紐約州)**：**0.16%**
* **State_Florida (佛羅里達州)**：**0.09%**

## 5. 商業決策建議 (Actionable Recommendations)

1. **研發支出是核心引擎**：無論哪種模型，研發支出都是獲利的最關鍵驅動力（重要性高達 91.7%）。企業應優先將資金配置於技術研發與產品創新。
2. **優化行銷配置**：雖然行銷投入與利潤正相關，但其邊際效益非常低（每 \$1.00 投入僅回收 \$0.03）。行銷活動應朝向精準定位與提高轉化率優化，避免盲目擴大預算。
3. **精簡行政管理開銷**：行政管理支出對利潤帶來微弱的負向效應，說明行政開銷是單純的成本負擔，企業應盡可能精簡行政流程，控制日常開銷。
4. **不必糾結公司選址**：在排除了 dummy variable trap 後，佛州與紐約州相較於加州並無實質的獲利優勢，模型重要性佔比均低於 0.2%。公司選址應以租金、稅收及人才獲取成本為首要考量，毋需迷信特定創業熱點州。
