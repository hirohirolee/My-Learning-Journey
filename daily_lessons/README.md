## 🛠️ 專案實作亮點 3：50 Startups 利潤預測與重構
* **技術棧**：`pandas`, `scikit-learn`, `plotly`, `Streamlit`
* **實作內容**：
    1. 使用 IQR 四分位距自動清洗離群值，並透過 One-Hot 編碼處理類別變數以防止虛擬變數陷阱。
    2. 整合五種機器學習迴歸模型，在背景重新訓練並對比 $R^2$、MAE 與 RMSE。

    4. 支援 CSV 自訂數據動態上傳重訓與 Plotly 實時聯動圖表展示。
