TOP 10 MACHINE LEARNING ALGORITHMS

機器學習十大演算法：核心原理、經典應用與實戰圖鑑

NCHU AI TRAINING班 專屬速查 符合 CRISP-DM 專案實務架構
排名 演算法名稱 學習型態 核心主要用途 (Main Use) 運作邏輯與核心原理解析 (Key Idea)
1
線性回歸
Linear Regression
 監督式 📈 預測連續型數值良率、金額 尋找一條誤差平方和最小的完美趨勢直線 $y = wx + b$，用來鎖定自變數與目標值之間的固定變動規律。
2
邏輯回歸
Logistic Regression
 監督式 🛑 二分法分類、機率估算 透過 Sigmoid 函數將任何數值訊號壓縮至 $0$ 到 $1$ 之間，代表機率，用以切割出「是不是/好與壞」的二元清晰邊界。
3
K-近鄰演算法
K-Nearest Neighbors (KNN)
 監督式 📍 直覺分類與鄰近偏好推薦 貫徹「物以類聚」觀念。新資料進來時完全不需複雜訓練，直接計算距離，看最近的 $K$ 個鄰居誰佔多數，就決定自己是哪類。
4
決策樹
Decision Tree
 監督式 🌿 白箱邏輯決策、資格審查 運用訊息增益（如不純度 Gini）作為指標，像做心理測驗般建立一連串「是與否」的條件分支欄位篩選，規則最透明、最好解釋。
5
隨機森林
Random Forest
 監督式 🌲 高強度的通用分類與預測 集成學習（Ensemble）經典。隨機抽取數據樣本和特徵，建立數百棵獨立的決策樹進行多數決投票，大幅度降低單棵樹容易死背資料（過擬合）的偏誤。
6
樸素貝氏
Naive Bayes
 監督式 ✉️ 垃圾郵件過濾、文字情感分析 基於貝氏定理，並「樸素」地假設所有特徵欄位之間完全獨立互不影響。能在大規模文本中光速計算出機率分布，效率極佳。
7
支援向量機
Support Vector Machine (SVM)
 監督式 ⚔️ 精準圖像特徵與高維度分類 尋找一個具有最大安全邊際（Margin）的楚河漢界超平面來切開兩類資料。若資料混雜，還能使用「核技巧（Kernel）」拉高維度完美分類。
8
K-Means 分群
K-Means Clustering
 非監督式 👥 未知答案的使用者與客群劃分 在完全沒有正確標籤的狀況下，透過設定分群數 $K$，讓電腦不斷疊代，利用距離最小化將數據自動凝聚吸引成 $K$ 大堆族群。
9
主成分分析
PCA (降維瘦身)
 非監督式 📉 特徵減肥、防止維度災難 數據的精華濃縮相機。將高維度、具高度相關性的眾多欄位壓扁成少數幾個彼此獨立的主成分（PCs），保留最大變異數（精髓資訊）。
10
類神經網路 / 深度學習
Neural Networks
 混合/多層 🧠 複雜圖文模式、高度非線性辨識 模擬大腦神經元結構。透過將前面所學的大量回歸轉換堆疊成多層網路（Layers），讓電腦能完全自動化擷取多維度、極其複雜的特徵規律。
