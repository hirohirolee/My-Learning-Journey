Cloud Run 雙容器部署 (v3)
效能調校與 Secrets 注入
【v3 優化】：Webhook 增加記憶體與執行個體限制控制成本；Worker 關閉 CPU Throttling 以確保背景任務不中斷；利用 `--set-secrets` 自動將密鑰注入環境變數。
部署 Webhook 主服務
gcloud run deploy openclaw-proxy \ --source . \ --region asia-east1 \ --allow-unauthenticated \ --service-account openclaw-sa@openclaw-proxy.iam.gserviceaccount.com \ --memory 512Mi \ --max-instances 2 \ --min-instances 0 \ --set-env-vars GCP_PROJECT_ID=openclaw-proxy,ALLOWED_LINE_USER_ID=你的USER_ID,SERVICE_TYPE=webhook \ --set-secrets="LINE_CHANNEL_SECRET=LINE_CHANNEL_SECRET:latest,LINE_ACCESS_TOKEN=LINE_ACCESS_TOKEN:latest,GEMINI_API_KEY=GEMINI_API_KEY:latest,DRIVE_FOLDER_ID=DRIVE_FOLDER_ID:latest"
部署 Task Worker (No Throttling)
gcloud run deploy openclaw-worker \ --source . \ --region asia-east1 \ --no-allow-unauthenticated \ --no-cpu-throttling \ --service-account openclaw-sa@openclaw-proxy.iam.gserviceaccount.com \ --memory 1024Mi \ --max-instances 2 \ --min-instances 0 \ --set-env-vars GCP_PROJECT_ID=openclaw-proxy,SERVICE_TYPE=worker \ --set-secrets="LINE_CHANNEL_SECRET=LINE_CHANNEL_SECRET:latest,LINE_ACCESS_TOKEN=LINE_ACCESS_TOKEN:latest,GEMINI_API_KEY=GEMINI_API_KEY:latest,DRIVE_FOLDER_ID=DRIVE_FOLDER_ID:latest"
