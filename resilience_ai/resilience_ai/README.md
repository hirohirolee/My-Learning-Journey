# 🛡️ 企業數位韌性審計預警系統 (Enterprise Digital Resilience Audit Warning System)

> **企業級雙軌合規自動化平台** —— 融合 **ISO 14064-1 溫室氣體盤查**、**ISO 27001 資訊安全管理** 與 **生管生產線 SOP** 的混合雲架構稽核與矯正預警系統。

---

## 📌 專案定位

本系統專為**上市櫃製造業**量身打造，針對現代企業面臨的「碳邊境關稅（CBAM）」與「企業永續資訊安全（SecOps）」雙重挑戰，提供全自動化的數位合規審計解決方案。

在製造業數位轉型的過程中，異常事件的發生（如碳排放超標、深夜敏感資料庫導出、生產線良率低下）往往分散在不同的系統孤島中。本系統能夠**即時接收異質系統數據，進行資料去識別化隱私防護，透過向量資料庫（RAG）匹配 ISO 合規條文與廠內 SOP，並由 AI 自動生成具體、可執行的 CAPA（矯正與預防措施）報告**，將企業的合規應變時間（MTTR）從數天縮短至分鐘級。

---

## 🏗️ 混合雲相容技術架構

為了同時兼顧**企業地端部署的隱私安全性**與**雲端展示的便利性**，本系統採用了「混合雲相容架構」：

```
                      ┌──────────────────────────────────────────┐
                      │        企業異質資料輸入 (API Payload)    │
                      └────────────────────┬─────────────────────┘
                                           │
                                           ▼
                      ┌──────────────────────────────────────────┐
                      │    FastAPI 後端核心 (去識別化 & 風險評級) │
                      └────────────────────┬─────────────────────┘
                                           │
                                           ▼
                      ┌──────────────────────────────────────────┐
                      │      ChromaDB 向量資料庫 (相對路徑)       │
                      └────────────────────┬─────────────────────┘
                                           │
                         ┌─────────────────┴─────────────────┐
                         │                                   │
              (優先嘗試地端連線)                       (連線失敗或超時 3s)
                         ▼                                   ▼
        ┌──────────────────────────────────┐        ┌──────────────────────────────────┐
        │  [地端私有化引擎 - 數據不落地]    │        │  [雲端備援引擎 - 展示分流方案]    │
        │  • Ollama 執行 qwen2.5:14b       │        │  • Google GenAI SDK              │
        │  • 100% 地端運行，零外部傳輸      │        │  • gemini-2.5-flash 推理         │
        │  • 輸出日誌: [Mode: Local]       │        │  • 輸出日誌: [Mode: Cloud]       │
        └────────────────┬─────────────────┘        └────────────────┬─────────────────┘
                         │                                   │
                         └─────────────────┬─────────────────┘
                                           ▼
                      ┌──────────────────────────────────────────┐
                      │       Streamlit 旗艦級 Dashboard 展示     │
                      └──────────────────────────────────────────┘
```

*   **地端生產模式（安全合規優先）**：系統優先尋求地端運行的 Ollama 服務。資料完全在企業內網不落地進行 RAG 稽核推理，確保商業機密與 ISO 27001 隱私規範。
*   **雲端展示模式（全自動無痛切換）**：當系統部署至 Streamlit Community Cloud 等外部環境時，後端會自動偵測地端 Ollama 連線逾時（設有 3 秒短連線超時），並「全自動、無痛切換」至雲端備援方案，使用官方最新 `google-genai` SDK 呼叫 `gemini-2.5-flash`，實現高可用性展示。
*   **向量資料庫相對路徑化**：ChromaDB 採用動態相對路徑化技術，不論是地端伺服器啟動還是在 Streamlit Cloud 環境中，皆能單機讀取隨代碼推至 GitHub 的 `audit_db` 向量知識庫。

## 🛠️ 技術棧選型

| 技術元件 | 選擇方案 | 決策考量與優勢 |
|:---|:---|:---|
| **後端 API 引擎** | **FastAPI** | 高性能非同步 (AsyncIO) 架構，具備原生 Pydantic 數據校驗與自動 OpenAPI 文件生成。 |
| **前端儀表板** | **Streamlit** | 以數據為中心的高級 Dashboard，支援動態報表與合規任務監控。 |
| **向量資料庫** | **ChromaDB** | 輕量化、易於隨程式碼打包的 Embedding 儲存庫，支援離線單機快速 RAG 檢索。 |
| **地端推論 LLM** | **Ollama (Qwen 2.5:14b)** | 製造業專屬微調推理能力，具備優異的中文合規理解與 CAPA 格式輸出能力。 |
| **雲端備援 LLM** | **Google Gemini 2.5 Flash** | 藉由 2026 最新官方 `google-genai` 軟體開發套件，提供高速度、極低延遲與強大長文本檢索能力的雲端模型支援。 |

## 🚀 3分鐘快速本地部署指南 (Windows 環境)

本指南專為 Windows 環境設計，使用 PowerShell 或 CMD 均可快速完成部署。

### 前置準備
1. 安裝 [Python 3.11+](https://www.python.org/downloads/)
2. 安裝 [Ollama](https://ollama.com/) 並啟動地端模型：
   ```powershell
   ollama run qwen2.5:14b
   ```

### 部署步驟

#### 1. 克隆專案與環境準備
打開 PowerShell 執行以下命令：
```powershell
# 克隆專案到本地
git clone https://github.com/您的帳號/resilience_ai.git
cd resilience_ai

# 建立 Python 虛擬環境
python -m venv .venv

# 啟用虛擬環境
.\.venv\Scripts\activate
```

#### 2. 安裝依賴套件
```powershell
# 升級 pip 並安裝系統所需套件 (已包含 google-genai)
python -m pip install --upgrade pip
pip install -r requirements.txt
```

#### 3. 設定環境變數
在專案根目錄下建立 `.env` 檔案，或將 `.env.example` 複製為 `.env`：
```powershell
copy .env.example .env
```
編輯 `.env` 內容（若需測試雲端備援，請填入 Gemini API 金鑰）：
```env
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=qwen2.5:14b
GEMINI_API_KEY=your_gemini_api_key_here
```

#### 4. 啟動後端與前端服務
啟動本系統需要同時執行後端與前端。

*   **步驟 A：啟動 FastAPI 後端**（開啟一個新終端機，啟用虛擬環境後執行）：
    ```powershell
    uvicorn backend.main:app --reload --host 127.0.0.1 --port 8000
    ```
*   **步驟 B：啟動 Streamlit 前端**（再開啟一個新終端機，啟用虛擬環境後執行）：
    ```powershell
    streamlit run app/app.py
    ```

## 💼 商業價值與 ROI 論述

本系統的架構設計能為上市櫃製造企業帶來顯著的商業價值：

1.  **降低合規事件應變時間 (MTTR)**
    傳統 ISO 審計與安全事件調查需動員資安、環安衛 (EHS) 與生產主管進行跨部門調查，平均應變時間高達 48 小時。本系統可在異常觸發的 **10秒內** 組裝上下文並產出標準 CAPA 報告，將 MTTR 降至分鐘級，避免產線因停工或違規面臨的高額罰鍰。
2.  **去識別化與隱私安全保障 (PII 保護)**
    系統原生提供敏感隱私去識別化引擎。在傳送至外部或本地 LLM 進行推理前，自動將員工姓名、身分證號、IP 位址等去識別化，符合 ISO 27001 標準與歐盟 GDPR 對隱私保護的嚴格要求。
3.  **地端運行的零邊際 Token 成本**
    系統在地端部署時採用開源的 Qwen 2.5 模型，所有的稽核、模擬、日常預警皆在企業本地伺服器內運算。這使得企業可進行**無限次、高頻率的自動化合規掃描**，而無需負擔昂貴的外部 API 費用，邊際成本降至零。
4.  **高可用性的彈性災備能力**
    雙軌制的自動切換設計，確保系統在本地伺服器維護或離線時，仍能藉由安全通道將去識別化後的數據交由雲端 Gemini 完成備援推理，保證了核心審計業務的連續性。
